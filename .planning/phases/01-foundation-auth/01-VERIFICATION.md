## Gaps Summary

Two gaps block complete goal achievement:

**Gap 1 (Blocker): Trial badge logic wrong value.** `Header.tsx` checks `subscriptionStatus === 'trialing'` but the `companies.plan_status` DB column uses the value `'trial'`. This means the trial badge — part of the success criterion "App shell renders: dark sidebar, header with notification bell, breadcrumbs" — will never appear for any real user. The fix is a two-character change in two files.

**Gap 2 (Partial): `supabase gen types typescript` untested.** The `src/types/database.ts` file was hand-crafted because Docker was unavailable during execution. The `db:types` npm script declared in the plan is also missing from `package.json`. The CLI round-trip has not been verified. This is recoverable once Docker is available — the hand-crafted types appear accurate, and if the CLI output differs, any type errors will surface at build time.

Both gaps are straightforward to fix. The foundation (schema, RLS, auth flow, app shell structure) is solid. Only these two items prevent the phase from fully meeting its stated success criteria.
